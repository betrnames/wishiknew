# Wish I Knew

**wishiknew.lol** — launches and patterns you wish you’d seen **before they went viral**.

Primary product: discovery feed (“missed boats”).  
Optional side mode: **Meme lab** (archived generator in `src/archive/` + `src/modes/MemeLab.tsx`).

## Local

```bash
npm install
cp .env.example .env.local   # optional Supabase keys
npm run dev
```

## Stack

Vite · React · TypeScript · Tailwind · shadcn/ui

## Notes

Do not commit `.env` / `.env.local`.
